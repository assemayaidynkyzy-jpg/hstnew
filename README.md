# The Esnaf and the Patrona Halil Rebellion of 1730 (Olson, 1974)

HST 271 reading presentation, Nazarbayev University.
Reading: Robert W. Olson, "The Esnaf and the Patrona Halil Rebellion of 1730: A Realignment in Ottoman Politics?", *Journal of the Economic and Social History of the Orient* 17(3), 1974, pp. 329–344.
Professor: Halit Akarca. Presenters: Assemay and Zhamilya.

## View it

- **On your computer:** open `index.html` in Chrome, Edge or Firefox. No install needed.
- **On GitHub Pages:** push this folder to a repository, then go to *Settings → Pages → Build and deployment → Deploy from a branch*, choose `main` and `/ (root)`. The deck appears at `https://<your-username>.github.io/<repository-name>/`.
- **As a PDF:** `slides.pdf` has all 18 slides.

## Presenter tools

A toolbar appears when you move the mouse and hides after a few seconds.

| Key | Action |
| --- | --- |
| ← / → (or click, swipe) | Previous / next slide |
| G | All slides, click one to jump to it |
| T | Start / pause the timer (default 20 minutes) |
| + / − | Add / remove one minute |
| R | Reset the timer and speaking times |
| P | Hand over to the other presenter (tracks speaking time for each) |
| N | Speaker notes |
| D | Night mode |
| F | Fullscreen |
| ? | Shortcut list |

Print or save as PDF with Ctrl/Cmd + P (one slide per page).

## Edit it

- **Team and talk length:** the first two lines of `assets/deck.js` (`PRESENTERS`, `TOTAL_MIN`).
- **Automatic handover:** add `data-presenter="0"` (Assemay) or `data-presenter="1"` (Zhamilya) to a `<section>` in `index.html`, and the speaker switches when that slide appears.
- **Speaker notes:** the `data-notes` attribute on each `<section>`.
- **Colors:** the variables at the top of `assets/style.css` (burgundy, beige, ochre, teal).
- **Images:** `assets/img/`. Keep the file names, or update the `<img src>` in `index.html`.
